# 直播吧

独立模块 **Zhibo8 Ad Filter**，用于关闭已观察到的广告配置，并拦截对应广告服务。无需编辑或替换主配置。

## 安装

在 Surge 的「首页 → 修改 → 模块 → 安装新模块」中添加：

```text
https://raw.githubusercontent.com/realyn/surge-ad-filters/main/apps/zhibo8/Zhibo8.sgmodule
```

启用模块，确认外部脚本下载成功，且 MitM 证书已完全信任、MitM 与脚本已开启。关闭同名本地测试模块，避免重复处理。将直播吧从后台关闭后重新打开；旧广告配置可能需要再次启动才被替换。

## 处理范围与依据

| 入口 | 处理方式与依据 |
| --- | --- |
| `a.qiumibao.com/ios/config/` | 实际响应含独立 `advert`、`advert_config` 字段；关闭广告、开屏、插屏、弹窗、预加载开关，清空广告活动列表。保留新闻、比分、视频、通知提示、账号及其他配置。 |
| `s.qiumibao.com/activities/material/json.htm` | 配置中的广告素材预加载接口，按完整路径拒绝。 |
| `ggtg.duoduocdn.com`、`sdkquic.e.qq.com`、`tk.lanjingads.com` | 启动期间观察到的广告服务；其中 `/launch` 返回广告 SDK 数据。按域名拒绝。 |
| `47.111.8.123:8091`、`118.178.168.156:8091`、`47.99.237.245:8091` | 启动及广告加载时出现的服务和备用地址。配置明确包含 `118.178.168.156:8091/allOne.php?ad_name=…`；逐个拦截后观察到备用地址切换，最终首页广告位消失。只匹配这些地址的 **8091 端口**。 |

MitM 只追加 `a.qiumibao.com`、`s.qiumibao.com`。为使响应过滤能够执行，模块给精确的 `/ios/config/` 接口添加 `DIRECT`；它优先于主配置中对该接口的拒绝规则。其他分流规则保留。

广告 SDK 域名规则会同时作用于其他应用访问同一广告服务的请求。没有屏蔽整个 `qiumibao.com`、`duoduocdn.com`，也没有全局屏蔽 8091 端口。

## 实机验证

2026-10-17，直播吧 iOS **6.9.7**、iOS **18.7**，在已有去广告规则的 Surge 环境中验证：

- 最终组合启用后，重新启动未见开屏广告、首页弹窗；首页第五项的「广告」条目消失。
- 正常新闻正文、图片预览、评论与回复加载正常。
- 足球短视频连续播放，比赛视频直播、实时比分及文字直播正常加载。
- 关闭诊断捕获后再次复测；模块可独立关闭，主配置文件校验值不变。

仅修改广告配置并不足以清除全部广告，实测需要配合广告服务拦截。上述结果是在原有规则基础上得到，尚未在全新空白配置、所有频道或所有广告形式中验证。应用可能更换备用 IP，旧素材也可能缓存；不能保证所有广告永久消失。赞助内容、普通推荐与会员功能保持原样。

公开测试只使用人工构造的数据，覆盖正常内容保留、精确接口范围、异常数据原样通过及端口规则边界。未公开抓包、账号、设备标识或个人配置。

## 更新与撤销

在 Surge 中更新已安装模块和外部资源；脚本固定到发布标签。出现异常时关闭本模块并重新启动直播吧，可恢复后续请求的原始处理。模块不会删除应用缓存或改动账号。
